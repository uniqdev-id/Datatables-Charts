📊 Configuration Examples

Here's how easy it is to use themes in your DataTables configuration:

Basic Theme Usage:

// Simple theme selection $('#example').DataTable({ dom: 'Bfrtip', buttons: [{ extend: 'charts', text: '📊 Chart Options', theme: 'dark', // Set your theme here! charts: [/* your chart definitions */] }] });

Advanced Theme with Custom Colors:

// Theme with custom color overrides $('#example').DataTable({ dom: 'Bfrtip', buttons: [{ extend: 'charts', text: '📊 Chart Options', theme: 'dark', colors: { primary: '#your-brand-color', background: 'transparent', text: '#ffffff' }, charts: [/* your chart definitions */] }] });
