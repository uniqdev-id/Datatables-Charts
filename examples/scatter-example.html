📊 DataTables Charts - Scatter Graph Example

This page demonstrates the newly added Scatter Graph support. Scatter charts are perfect for analyzing relationships between two numerical columns (e.g., Price vs Profit) across items.

Key Features Highlighted:

  • Category Clustering: Points are grouped and colored by mapping a clusterColumn (e.g., Category) from the table.
  • Dynamic K-Means Clustering: Automatically compute and group points into mathematical clusters using clusters: 3 (no pre-defined cluster column needed).
  • Smart Tooltips: Hovering over a point displays its product name (from labelColumn) along with axis-specific values instead of raw coordinates.
  • Auto-Refresh: The chart dynamically updates when you search or filter the table. Try typing "Furniture" in the search box to filter the clusters!
